# Knowbility marketplace

Claude Code plugins for accessible software delivery, owned and maintained by Knowbility.

Each plugin here is small, focused, and standalone. Install one or all of them, in any order; none
depends on another.

## Install

```
/plugin marketplace add knowbility/knowbility-marketplace
/plugin install <plugin>@knowbility
```

This repository is private, so you need read access on the `knowbility` GitHub organization and
working git credentials on the machine you are installing from.
